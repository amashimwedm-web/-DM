# Togetherly

A supportive marriage-planning companion for couples. Plan your life together at your own pace, wherever you are.

## Features

- Flexible relationship and wedding planning roadmap
- Guided conversations about values, money, family, home, children, work, and support
- Editable wedding budget with multiple currencies
- Ceremony and celebration planning tasks
- Couple profile and shared goals
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in any modern browser. No build tools are required.

## GitHub Pages

This site is published directly from the root of the `main` branch in this public repository: https://github.com/amashimwedm-web/-DM

## Current prototype limitations

This is a front-end prototype. Information is saved in local browser storage on the current device. There are no accounts, shared cloud data, or connected AI service yet. Do not enter sensitive personal or financial information.

This planning companion is not a substitute for local legal, financial, medical, or relationship professionals.
